Como instalar

  1. Baixe o arquivo iptv-caseiro.apk.
  2. Abra o download e permita a instalação dessa fonte quando o Android solicitar.
  3. Abra o app e informe o endereço do servidor, como http://192.168.1.20:5000.
  4. Nas próximas versões, use o botão Atualizar dentro do aplicativo.
O app solicita somente internet, estado da rede e autorização para abrir a instalação de atualizações.
