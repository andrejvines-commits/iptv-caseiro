# Notas de atualização

## Retomada de séries

- O aplicativo salva automaticamente o episódio assistido e o ponto exato de reprodução.
- Ao abrir novamente uma série, ela continua no último episódio não concluído, a partir do tempo salvo.
- Episódios concluídos deixam de aparecer como conteúdo pendente.
- A área **Continuar assistindo** mostra os conteúdos que ainda podem ser retomados.
